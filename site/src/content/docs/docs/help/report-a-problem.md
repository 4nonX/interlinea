---
title: Report a problem
description: What to put in a bug report so it can be fixed, and where to send it.
---

Bugs and wishes go to the
[issues on GitHub](https://github.com/4nonX/interlinea/issues). You need a
free GitHub account to open one.

## What helps

- **The version:** Settings, About Interlinea.
- **Your system:** Windows, macOS or Linux, or the browser and its version.
- **What you did, what you expected, and what happened instead.**
- **The file**, if the problem is with one: the file you were sent, not
  the translated one. Only attach files you may share. A client's
  document usually can't be shared; then say which program made it and
  what is in it (tables, tracked changes, a package with 12 files), or
  make a small file that shows the same problem.
- **A screenshot** of what looks wrong.

## Before you open one

Search the [open issues](https://github.com/4nonX/interlinea/issues)
first; if yours is there, add what you know to it.

A security problem goes privately to the maintainers, not into an open
issue: use [report a vulnerability](https://github.com/4nonX/interlinea/security/advisories/new)
on GitHub. [SECURITY.md](https://github.com/4nonX/interlinea/blob/main/SECURITY.md)
says what to put in the report.
