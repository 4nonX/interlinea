## What does it cost?

Nothing. Interlinea is free software under the GNU Affero General Public
License, version 3. You can use it for paid work.

## Do I need an account?

No. The desktop app and the browser client work on your own computer
without an account or a network. Accounts exist only on a team server.

## Can I work on files from Trados and memoQ clients?

Yes. Interlinea opens SDLXLIFF and MQXLIFF files, Trados project packages
(.sdlppx) and memoQ handoff packages (.mqout), and the review tables of
Trados, memoQ and Déjà Vu, and writes them back. Check the first ones
before delivery; see
[check a file before delivery](/docs/help/check-before-delivery/).

## Can I bring my memories and termbases?

Memories from TMX, Trados Studio (.sdltm) and Wordfast; termbases from
TBX, MultiTerm XML and .sdltb, CSV, TSV and Excel.

## Which languages does the interface speak?

English, German and Korean. The languages you translate between are a
different list; [languages](/docs/manual/languages/) has it, with the
spelling dictionaries included for 22 of them.

## Does it use machine translation?

Only if you turn it on. DeepL, Google, Microsoft or a language model can
suggest translations with the key of your own account; see
[translation services and assistants](/docs/manual/integration/).

## Why does my system warn me when I install it?

The Windows installer is not signed and the macOS app is not notarized
yet. [Install Interlinea](/docs/help/install/) shows how to open it the
first time.

## Is it finished?

No. It is version 0.x and being tested by translators now. Expect rough
edges, and please
[report what you find](/docs/help/report-a-problem/).
